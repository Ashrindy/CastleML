# Castle Mod Loader
A mod loader for the game Castle Strike. Meant to be used with the [Castle Mod Manager](https://github.com/Ashrindy/CastleModManager). <br/>
**Highly recommended to download builds through the Mod Manager, and not manually.**
## Building 
### Windows
Requires [MinGW](https://github.com/niXman/mingw-builds-binaries) and [CMake](https://cmake.org/)
```
$ cmake .. -B build --preset mingw-windows-release
$ cd build
$ mingw32-make -j 8
```
